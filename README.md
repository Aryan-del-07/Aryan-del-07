## Featured Projects

### [StudZens](https://github.com/Aryan-del-07/studzens)
Full-stack college recommendation platform for Indian students. Enter your JEE/NEET/BITSAT scores and get colleges ranked as Safe, Reach, or Backup — with match scoring, side-by-side comparison, an interactive map, and a career explorer. Built as an npm monorepo: React 19 frontend, Express + Prisma backend, Neon PostgreSQL, deployed on Railway.

### [Lumina AI](https://github.com/Aryan-del-07/Lumina_AI)
AI-powered book marketplace that uses Google Gemini with Search Grounding to fetch real-time book data — live ratings, verified covers, and sourced summaries. Includes a cover scanner that identifies books and suggests resale prices using Gemini Vision, and a conversational AI literary guide.

### [EverShop on AWS](https://github.com/Aryan-del-07/Evershop_project)
Production deployment of an e-commerce platform on AWS — EC2 instances behind an Application Load Balancer with Auto Scaling, RDS for the database, S3 + CloudFront for static assets and CDN, Route 53 for DNS, and ACM for SSL. Documented the full architecture and setup process.

### [Personal Finance Tracker](https://github.com/Aryan-del-07/Personal-Finance-Tracker)
Python CLI tool for tracking income and expenses. Supports date-range filtering, transaction summaries with net balance calculation, and pie chart visualization. Built with Pandas and Matplotlib.

## AI-Assisted Engineering

I use AI coding tools — primarily Claude, along with other LLM-based tools — as part of my daily engineering workflow. Not as a replacement for understanding, but as a way to move faster and dig deeper:

- **Investigating problems** — understanding unfamiliar codebases, tracing bugs, reading documentation
- **Prototyping** — quickly testing API integrations, data models, and architectural ideas
- **Debugging** — getting a second perspective on error traces and edge cases
- **Research** — exploring libraries, comparing approaches, understanding trade-offs

I think of AI tools the way I think of a good debugger or a well-written Stack Overflow answer — they accelerate the work, but I still own the code, review every change, and understand why things work (or don't).

This matters to me because I'm specifically interested in **AI engineering** — not just using AI, but understanding how to build with it effectively.
